## Output Description

The Personal Portfolio Website displays an attractive and well-organized webpage containing all the important personal and professional details of an individual.

When the website is opened in a browser, the Home page displays a welcome message with the person's name, role, and a navigation menu. Users can navigate between different sections by clicking the menu links.

The website displays the following sections:

1. Home: Displays a welcome message and introduction.
2. Profile: Displays the individual's photograph and personal introduction.
3. Educational Qualifications: Shows school, college, university, course details, and academic percentages.
4. Technical Skills: Displays skills such as HTML, CSS, Python, and JavaScript using animated progress bars.
5. Hobbies: Shows hobbies such as reading, coding, listening to music, and playing sports.
6. Projects: Displays completed projects with their titles and descriptions.
7. Achievements: Highlights academic achievements, technical competitions, and certificates.
8. Resume: Provides a button to download the individual's resume in PDF format.
9. Contact Information: Displays email address, phone number, location, and LinkedIn profile.

Visual Output:

- The website has a blue and white colour theme.
- Navigation links change colour when clicked or hovered over.
- Project and information cards move upwards when the mouse pointer hovers over them.
- Skill bars animate when displayed.
- Smooth scrolling allows users to move between sections.
- The responsive layout adjusts automatically to different screen sizes, including mobiles, tablets, and desktops.

Result: The Personal Portfolio Website is successfully created using HTML, CSS, and JavaScript. It provides an attractive, interactive, and responsive platform to showcase an individual's profile, education, technical skills, hobbies, projects, achievements, resume, and contact details.
